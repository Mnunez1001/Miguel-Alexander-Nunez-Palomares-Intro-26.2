## About The Project

This portfolio was developed as part of the Code the Dream Intro to Programming course and has evolved into a professional portfolio used to showcase my work to employers, collaborators, and internship opportunities.

The website highlights:

- Academic background
- Research experience
- Leadership programs
- Technical skills
- Software development projects
- GitHub repositories
- Open API demonstrations
- Professional contact information

The goal of this project is to create a centralized location where visitors can learn about my technical experience and explore projects that demonstrate my skills in software development, data engineering, cybersecurity, networking, and computer science.
